╔════════════════════════════════════════════════════════════════════════════╗
║                         REQUEST FLOW EXAMPLE                              ║
╚════════════════════════════════════════════════════════════════════════════╝

USER SUBMITTING A COMPLAINT:

   ┌─────────────────────────────────────────────────────────────────────┐
   │ 1. User fills form in submit-complaint.html and clicks "Submit"     │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 2. submit-complaint.js validates form and makes API call:           │
   │    POST http://localhost:5000/api/complaints                         │
   │    {                                                                 │
   │      "description": "Street damaged",                               │
   │      "location": "Street A, Area B",                                │
   │      "phone": "9876543210"                                          │
   │    }                                                                 │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 3. Flask receives request in complaint_routes.py                    │
   │    - Creates new Complaint object                                   │
   │    - Calls utils.classify_complaint() for AI classification         │
   │    - Saves to database using SQLAlchemy ORM                         │
   │    - Calls utils.send_email() for notifications                     │
   │    - Returns JSON response with complaint ID                        │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 4. JavaScript receives response and shows confirmation              │
   │    "Complaint submitted! ID: COMP123"                               │
   └─────────────────────────────────────────────────────────────────────┘


ADMIN VIEWING DASHBOARD:

   ┌─────────────────────────────────────────────────────────────────────┐
   │ 1. Admin logs in via admin-login.html                               │
   │    - Enters email & clicks send OTP                                 │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 2. Flask auth_routes.py:                                            │
   │    - Finds admin in database                                        │
   │    - Calls utils.generate_otp()                                     │
   │    - Calls utils.send_email() with OTP                              │
   │    - Stores OTP in otp_storage.json                                 │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 3. Admin receives OTP email, enters it, clicks verify               │
   │    POST /api/auth/verify-otp with OTP code                          │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 4. Flask verifies OTP, creates AdminSession, stores session token   │
   │    Returns session token in JSON response                           │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 5. admin-login.js receives token, stores it, redirects to dashboard │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 6. admin-dashboard.html loads                                       │
   │    - JavaScript fetches data:                                       │
   │      GET /api/admin/dashboard (with session token header)           │
   │      GET /api/admin/analytics                                       │
   │      GET /api/admin/complaints                                      │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 7. Flask admin_routes.py returns data from database                 │
   │    - Queries complaints table                                       │
   │    - Calculates statistics                                          │
   │    - Filters based on admin's role/zone/circle                      │
   └────────────────────────┬────────────────────────────────────────────┘
                            │
                            ▼
   ┌─────────────────────────────────────────────────────────────────────┐
   │ 8. admin-dashboard.js receives data and renders:                    │
   │    - Statistics cards                                               │
   │    - Charts & graphs                                                │
   │    - Complaints table                                               │
   │    - Filters and search                                             │
   └─────────────────────────────────────────────────────────────────────┘

║                    DEPLOYMENT STRUCTURE                                    ║
╚════════════════════════════════════════════════════════════════════════════╝

For production deployment:

backend/                    → Deploy on server/cloud (Python)
  ├── app/
  ├── scripts/
  ├── run.py
  └── requirements.txt

frontend/                   → Serve on web server/CDN (static files)
  ├── *.html               → No build needed
  ├── css/
  └── js/

data/                       → Keep on same server as backend
  └── grievance.db         → SQLite database

models/                     → Deploy with backend
  └── *.pkl                → ML models


╔════════════════════════════════════════════════════════════════════════════╗
║                     TECHNOLOGY STACK                                       ║
╚════════════════════════════════════════════════════════════════════════════╝

BACKEND:
  • Language: Python 3.8+
  • Framework: Flask (REST API)
  • ORM: SQLAlchemy
  • Database: SQLite
  • Email: SMTP
  • ML: scikit-learn, pickle
  • AI: Google Gemini API

FRONTEND:
  • Markup: HTML5 (semantic)
  • Styling: CSS3 (responsive, flexbox)
  • Scripting: Vanilla JavaScript (ES6+)
  • API Calls: Fetch API
  • Storage: localStorage (session tokens)
  • No build process required

DEPLOYMENT:
  • Backend: Python server (Flask)
  • Frontend: Static file server (HTTP)
  • Database: SQLite (file-based)
  • Models: Included with backend
