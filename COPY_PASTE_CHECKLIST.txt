🚀 QUICK START COMMANDS
═══════════════════════════════════════════════════════════════════════════════

  python -m venv venv
  source venv/bin/activate     # or venv\Scripts\activate on Windows
  pip install -r requirements.txt
  python run.py

Terminal 2 (Frontend):
  cd frontend
  python -m http.server 8000

Browser:
