🎯 STEP 1: CREATE FOLDER STRUCTURE (2 minutes)
═════════════════════════════════════════════════════════════════════════════════

In your project, create these folders:

  📁 backend
  📁 backend/app
  📁 backend/app/routes
  📁 backend/scripts
  📁 frontend
  📁 frontend/css
  📁 frontend/js

That's it for folders!


📋 STEP 2: COPY 24 FILES (15 minutes)
═════════════════════════════════════════════════════════════════════════════════

Copy these 13 files to backend/:
  ✓ run.py
  ✓ requirements.txt
  ✓ .env.example
  ✓ app/__init__.py
  ✓ app/models.py
  ✓ app/utils.py
  ✓ app/routes/__init__.py
  ✓ app/routes/auth_routes.py
  ✓ app/routes/complaint_routes.py
  ✓ app/routes/admin_routes.py
  ✓ app/routes/zone_routes.py
  ✓ scripts/__init__.py
  ✓ scripts/seed_db.py

Copy these 11 files to frontend/:
  ✓ index.html
  ✓ submit-complaint.html
  ✓ track-complaint.html
  ✓ admin-login.html
  ✓ admin-dashboard.html
  ✓ css/style.css
  ✓ js/config.js
  ✓ js/submit-complaint.js
  ✓ js/track-complaint.js
  ✓ js/admin-login.js
  ✓ js/admin-dashboard.js

HOW TO COPY:
1. In V0, click on file
2. Select all (Ctrl+A)
3. Copy (Ctrl+C)
4. Create same file in your project
5. Paste (Ctrl+V)
6. Save

WHERE TO FIND FILES IN V0:
  → Click the folder icon on the RIGHT side
  → Navigate through backend/ and frontend/ folders
  → Click any file to see content
  → Full guide in: WHERE_TO_FIND_FILES.md


⚡ STEP 3: RUN BACKEND (5 minutes)
═════════════════════════════════════════════════════════════════════════════════

Open Terminal 1 and run these commands:

  cd backend
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements.txt
  python run.py

WINDOWS? Use this instead of "source venv/bin/activate":
  venv\Scripts\activate

WAIT FOR THIS MESSAGE:
  "Running on http://127.0.0.1:5000"

✓ Backend is running! Keep this terminal open.


🌐 STEP 4: RUN FRONTEND (2 minutes)
═════════════════════════════════════════════════════════════════════════════════

Open Terminal 2 (don't close Terminal 1!) and run:

  cd frontend
  python -m http.server 8000

WAIT FOR THIS MESSAGE:
  "Serving HTTP on 0.0.0.0 port 8000"

✓ Frontend is running! Keep this terminal open.

THEN OPEN YOUR BROWSER:
  http://localhost:8000

✅ APPLICATION IS NOW RUNNING! 🎉

❓ SOMETHING WENT WRONG?
═════════════════════════════════════════════════════════════════════════════════

"python: command not found"
  → Python not installed
  → Download from python.org
  → Try again

"No module named 'flask'"
  → Not in right folder or venv not activated
  → Make sure you're in backend/ folder
  → Make sure (venv) shows in terminal
  → Run: pip install -r requirements.txt

"Port already in use"
  → Try different port
  → Backend: python run.py --port 5001
  → Frontend: python -m http.server 8001

"Can't see files in V0"
  → Click folder icon on right side
  → Navigate folders
  → Full guide: WHERE_TO_FIND_FILES.md
