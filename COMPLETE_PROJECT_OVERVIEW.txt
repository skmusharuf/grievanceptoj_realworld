QUICK START (3 STEPS - 10 MINUTES)
═════════════════════════════════════════════════════════════════════════════════

Terminal 1 - Start Backend:
──────────────────────────
cd backend
python -m venv venv
source venv/bin/activate          # macOS/Linux
# OR venv\Scripts\activate        # Windows
pip install -r requirements.txt
python run.py
# Wait for: "Running on http://127.0.0.1:5000"


Terminal 2 - Start Frontend:
─────────────────────────────
cd frontend
python -m http.server 8000
# Wait for: "Serving HTTP on 0.0.0.0 port 8000"


Browser - Open Application:
────────────────────────────
http://localhost:8000


DONE! ✅ Application is running

TROUBLESHOOTING QUICK REFERENCE
═════════════════════════════════════════════════════════════════════════════════

PROBLEM: "Python not found"
SOLUTION: Install Python from python.org

PROBLEM: "Port 5000 in use"
SOLUTION: Change port in backend/run.py (line with port=5000)

PROBLEM: "Module not found"
SOLUTION: Make sure venv is activated and pip install was successful

PROBLEM: "Database error"
SOLUTION: Delete data/grievance.db and run python scripts/seed_db.py again

PROBLEM: "Frontend can't reach backend"
SOLUTION: Check frontend/js/config.js has correct API_BASE_URL = 'http://localhost:5000'

  • START_HERE.md → Troubleshooting section
