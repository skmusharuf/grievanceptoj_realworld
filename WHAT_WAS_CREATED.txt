FILE LOCATIONS REFERENCE
================================================================================

To Change Colors:
  → scripts/app/static/css/styles.css (look for :root section)

  → scripts/app/templates/*.html (edit the text directly)

  → scripts/app/static/css/*.css (add your CSS rules)

To Change Functionality:
  → scripts/app/static/js/*.js (modify JavaScript functions)

To Add New Page:
  1. Create scripts/app/templates/new-page.html
  2. Add route in scripts/app/routes/pages.py
  3. Link in navigation in base.html
