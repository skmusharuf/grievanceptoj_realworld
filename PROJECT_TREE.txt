═══════════════════════════════════════════════════════════════
QUICK START IN 3 COMMANDS
═══════════════════════════════════════════════════════════════

1. START BACKEND:
   cd backend && python -m venv venv && source venv/bin/activate && pip install -r requirements.txt && python run.py

2. START FRONTEND (in another terminal):
   cd frontend && python -m http.server 8000

3. OPEN BROWSER:
   http://localhost:8000

═══════════════════════════════════════════════════════════════
DATABASE SCHEMA (9 TABLES)
═══════════════════════════════════════════════════════════════

1. users                - End users submitting complaints
2. complaints           - Submitted grievances/complaints
3. zones                - Geographic zones (regions)
4. circles              - Geographic circles within zones
5. areas                - Geographic areas within circles
6. admins               - Admin users (super, sub, department)
7. admin_sessions       - Active admin sessions
8. location_logs        - User location tracking
9. otp_storage          - One-time passwords for verification


═══════════════════════════════════════════════════════════════
API ENDPOINTS (SUMMARY)
═══════════════════════════════════════════════════════════════

AUTHENTICATION:
  POST   /api/auth/login              - Admin login
  POST   /api/auth/verify-otp         - Verify OTP
  POST   /api/auth/logout             - Logout
  GET    /api/auth/user               - Current user

COMPLAINTS:
  POST   /api/complaints              - Submit complaint
  GET    /api/complaints              - List complaints
  GET    /api/complaints/<id>         - Get details
  GET    /api/complaints/<id>/status  - Get status
  PUT    /api/complaints/<id>/status  - Update status
  DELETE /api/complaints/<id>         - Delete

ADMIN:
  GET    /api/admin/dashboard         - Dashboard stats
  GET    /api/admin/analytics         - Analytics data
  GET    /api/admin/complaints        - Complaint list

ZONES:
  GET    /api/zones                   - All zones
  GET    /api/zones/<id>/circles      - Zone circles
  GET    /api/circles/<id>/areas      - Circle areas
