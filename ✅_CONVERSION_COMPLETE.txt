================================================================================
                    TROUBLESHOOTING
================================================================================

Issue: "python: command not found"
Solution: Install Python 3.8+ from python.org

Issue: "Port 5000 already in use"
Solution: Kill process on port 5000 or restart computer

Issue: "Voice input not working"
Solution: Check microphone permissions, use Chrome/Firefox, use localhost

Issue: "Area search empty"
Solution: Make sure backend is running (check terminal)

Issue: "Database error"
Solution: Run: python backend/scripts/seed_db.py

More help: See SETUP.md or FINAL_SUMMARY.md
