📋 WHAT EACH FILE DOES
═════════════════════════════════════════════════════════════════════════════════

BACKEND FILES:

run.py
  • Main entry point for Flask server
  • Starts backend on port 5000
  • Initializes database
  • Loads routes and config
  
app/__init__.py
  • Creates Flask app instance
  • Configures database
  • Registers blueprints (routes)
  
app/models.py
  • Defines 9 SQLAlchemy models:
    - User, Admin, AdminSession
    - Complaint, ComplaintStatus
    - LocationLog, SOSEvent, UserReport
    - OTPStorage
  • Database schema
  
app/utils.py
  • Email sending function
  • OTP generation & verification
  • AI-based complaint classification
  • Helper utilities
  
app/routes/auth_routes.py
  • POST /api/auth/otp-login - Login with OTP
  • POST /api/auth/verify-otp - Verify OTP
  • POST /api/auth/verify-user-otp - User verification
  • POST /api/admin/login - Admin login
  
app/routes/complaint_routes.py
  • POST /api/complaints - Submit complaint
  • GET /api/complaints - List complaints
  • GET /api/complaints/<id> - Get complaint detail
  • GET /api/complaints/<id>/status - Get status
  • PUT /api/complaints/<id> - Update complaint
  • DELETE /api/complaints/<id> - Delete complaint
  
app/routes/admin_routes.py
  • GET /api/admin/complaints - Get admin view
  • GET /api/admin/analytics - Get analytics
  • POST /api/admin/update-status - Update status
  • Other admin operations
  
app/routes/zone_routes.py
  • GET /api/zones - List zones
  • GET /api/circles - List circles
  • GET /api/areas - List areas
  
scripts/seed_db.py
  • Creates demo data
  • 12 zones, 60 circles, 300 areas
  • 3 admin users
  • Sample complaints
  • Runs automatically on startup

requirements.txt
  • Flask==3.0.0
  • Flask-SQLAlchemy==3.1.1
  • Other dependencies
  • Install with: pip install -r requirements.txt
