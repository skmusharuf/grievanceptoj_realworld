8️⃣  TROUBLESHOOTING (If Something Goes Wrong)
═════════════════════════════════════════════════════════════════════════════════

    PROBLEM                         SOLUTION
    ─────────────────────────────   ────────────────────────────────
    "python: command not found"     → Install Python 3.8+
    "No module named 'flask'"       → pip install -r requirements.txt
    "Port 5000 already in use"      → Change port in run.py
    "Port 8000 already in use"      → python -m http.server 8001
    "404 error"                     → Make sure you're in frontend/
    "Can't connect API"             → Check both servers running
    Files appear empty              → Check you're in correct folder
    "ModuleNotFoundError"           → Activate virtual environment

    STILL STUCK? → Read MASTER_SETUP_GUIDE.md (Troubleshooting section)
