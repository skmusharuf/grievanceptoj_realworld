🐛 COMMON PROBLEMS & SOLUTIONS
═════════════════════════════════════════════════════════════════════════════════

❌ "python: command not found"
   → Python not installed or not in PATH
   → Solution: Download Python 3.8+ from python.org
   → Choose "Add Python to PATH" during installation

❌ "ModuleNotFoundError: No module named 'flask'"
   → Virtual environment not activated
   → Solution: source venv/bin/activate (or venv\Scripts\activate)
   → Then: pip install -r requirements.txt

❌ "Port 5000 already in use"
   → Something else using port 5000
   → Solution: Change port in run.py or use different port

❌ "Port 8000 already in use"
   → Something else using port 8000
   → Solution: python -m http.server 8001 (use 8001 instead)

❌ "404 error at http://localhost:8000"
   → Not in frontend folder
   → Solution: Make sure you run http.server from frontend/ folder
   → Check frontend/index.html exists

❌ "Can't connect to backend API"
   → Backend server not running
   → Solution: Make sure Terminal 1 shows "Running on http://127.0.0.1:5000"
   → Start both servers before using app

For more help: MASTER_SETUP_GUIDE.md → Troubleshooting section
